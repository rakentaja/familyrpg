**Bottom line:** the model is at the ~90% ship gate. The Haiku rewrites helped a little on unseen wording, but the next real gain comes from **real GM requests**, not more synthetic data (see Next steps).

A model trained for 8 epochs was worse (135/150) and was deleted. The 4-epoch model is kept.

## What was done

The pipeline (`ai/src`, `ai/data`, `ai/train`, `ai/eval`, README) was built by the main session ("Tiny AI model for browser game editing"). That session also trained the template-only model. This session added the Claude Code rewrite route and the fresh test set, then retrained:

1. **`data/rewrite.ts` + `data/REWRITE.md`.** `split` writes 2,400 template programs into 24 batch files, each program with 4 style prompts (child, terse, voice, polite, typos, reordered…). Rewrite agents follow `REWRITE.md`. `merge` checks every rewrite through the real assembler: it must turn back into exactly the source command program, or it is dropped.
2. **Rewrites:** 1 pilot plus 6 parallel Haiku agents wrote 9,600 rewrites. **8,597 passed the check (89.6%)**, and 8,083 went into training after splitting.
   - Most failures were Haiku gluing punctuation to labels (`[SEP, then]`); the merge step now fixes that.
   - Remaining drops: 614 that don't round-trip, 191 unknown or misspelled names, 164 bad markup.
3. **`eval/heldout2.jsonl`:** 100 new test requests, not seen by the rewrite agents. I changed 3 labels after the first run, where my label was arguable ("put **the** X by …" = move, not add). Wired into `eval/run.ts` as the `heldout2` set.
4. **Retrained** on 41,907 rows (27.7k template + 8.1k rewrites + 6.1k augmented), 4 epochs, then exported and scored.

## Remaining misses on the fresh set (10)

- **"Turn" read as a lift** (`turn the bench to the right`).
- **"Move X to the middle/back"** became an edit or add.
- **Scene names** dropped or trimmed ("Chimney Hop", "The Toy Shop" → "Toy Shop").
- **`rooftops scene with lots of stuff`** read as a new scene instead of a recipe.
- **`star`** is ambiguous between the star token and the star prop.
- **"hide a grumpling behind the crates"** read as hiding an existing one; the request is arguable.

## Next steps

1. **Collect real requests.** Show the parsed command for one-tap confirm, and save every confirm or correction as `{text, dsl}`. Then label them with `bun data/paraphrase.ts --annotate` or via Claude Code, and retrain. About 100–300 real requests is what the literature says closes most of the remaining gap.
2. **Add templates for the misses above**, then rerun `bun data/gen.ts && bun data/build.ts`.
3. **Replace `heldout2`** with requests you write yourself over time. Opus drafted this set, so it is only an independent check, not ground truth.
4. **Add common misspellings** from `out/data/para.report.json` → `unknownNames` (e.g. "bel", "toy pil", "hole in teh ice") to the synonyms in `packs/sleighbound.ai.json`.

## How to re-run the rewrites

From `ai/`:

```
bun data/rewrite.ts split --n 2400 --batch 100 --per 4
# then in Claude Code: "follow ai/data/REWRITE.md for batches 000–023 using Haiku subagents, 4 batches each, 6 in parallel"
bun data/rewrite.ts merge
bun data/build.ts
cd train && uv run train_tagger.py && uv run export_tagger.py && cd ..
bun eval/run.ts --model gm-tagger --set heldout,heldout2,dev
```
